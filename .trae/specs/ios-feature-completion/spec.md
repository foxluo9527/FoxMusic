# FoxMusic iOS（KMP）功能补完 - 产品需求文档

## Overview
- **Summary**: 在已迁移大部分功能、可在 iOS 模拟器（FoxMusicSim）运行的 KMP 工程上，修复主题问题并补完首页列表页、社区发帖与后台任务、举报、歌曲菜单、消息聊天、下载、设置以及全新开发的锁屏/灵动岛歌词。
- **Purpose**: 使 iOS 端功能与安卓端对齐（第 1–9 项），并以 iOS 官方机制交付锁屏与灵动岛歌词（第 10 项，无安卓参考）。
- **Target Users**: FoxMusic iOS 端用户（内部测试阶段）。

## Goals
- 切换主题（深色模式/主题色）后，SwiftUI 外壳与 CMP 页面背景即时跟随。
- 首页三个「更多」落地页（全部歌单、为你精选/新歌速递、全部专辑）功能对齐安卓；列表点歌入队数量充足但不在首页展示完。
- 社区：帖子搜索、发布动态、发布任务状态页与后台任务管理（持久化、崩溃恢复、重试、取消）。
- 举报：通用举报能力覆盖歌曲/帖子/评论/用户；设置内提供举报历史管理。
- 歌曲更多菜单功能项与安卓一致。
- 消息：名片分享（分享选择好友）、消息与会话本地持久化、类 WorkManager 可靠发送与状态展示、语音/图片/视频/文件消息（含权限申请）。
- 下载：下载引擎（断点续传）+ 下载管理页 + 仅 Wi-Fi 策略 + 已下载播本地文件。
- 设置：编辑资料（图片上传流程 API 完全参考安卓）、隐私设置；移除「检查更新」。
- 全新：ActivityKit Live Activity 锁屏歌词 + 灵动岛（新增 Widget Extension target）。

## Non-Goals
- 不改动安卓端业务行为（安卓代码仅作参考；KMP commonMain 的必要修复需两端兼容）。
- 不做车载模式、桌面歌词、桌面 Widget 的迁移。
- 不新增后端接口（优先复用现有接口；如确需后端配合，记入 Open Questions 并暂停相关子项）。
- 不做应用内自建更新（iOS 随构建分发）。

## Background & Context
- 架构：`core/*`、`feature/*` 为 KMP 共享模块；iOS UI 主要由 Compose Multiplatform（CMP）渲染，通过 `foxComposeViewController` 产出 UIViewController，嵌入 SwiftUI 外壳（`iosApp/iosApp/*TabView.swift`）；播放内核为 Swift `PlayerModel`（AVPlayer）。
- 现状盘点（未提交工作区代码）：
  - 全部歌单（FoxPlaylistListScreens.kt）、全部专辑、推荐/新歌落地与 30 条队列预取池**已有实现**，需验证与补缺。
  - 帖子搜索 tab、FoxCreatePostScreen、FoxPostPublishQueue/Screen **已有雏形**；但 Swift 入口（社区发帖/队列）仍是 Toast 占位；发布队列为**纯内存**，杀进程即丢。
  - 聊天：仅内存态文本消息 + 4 秒轮询，无本地持久化；语音/图片/视频/文件、名片分享均为占位。
  - 下载：iOS 完全缺失；Info.plist 无任何隐私权限描述。
- iOS 平台约束：自定义锁屏界面不可行；锁屏歌词只能通过 ActivityKit Live Activity（iOS 16.2+）承载，交互按钮需 iOS 17+，宿主必须是 Widget Extension。工程部署目标 16.0，相关功能按系统版本可用性控制。

## Functional Requirements

### 主题
- **FR-1**: 切换深色模式（跟随系统/浅色/深色）或主题色后，所有 Tab 根页、导航栈二级页、CMP 页面背景、窗口补色在当前时刻重组跟随，无需重启 App。

### 首页列表
- **FR-2**: 首页「推荐歌单」更多 → 全部歌单页：分类 Tab（首位「推荐歌单」+ 动态分类）、4 列网格分页（pageSize=20），点击进入歌单详情。
- **FR-3**: 首页「为你精选」更多与发现页「新歌速递」更多 → 歌单列表形态页（虚拟歌单详情，sort=recommend/latest，上限 100 条，pageSize=30）；首页/发现页列表点击歌曲时，入队队列显著大于屏幕展示数（≥30 首，参考安卓 maxTotalItems=100 的口径）但页面只展示前几条。
- **FR-4**: 首页「热门专辑」更多 → 全部专辑页：TopAppBar + 4 列网格分页（pageSize=20，GET api/albums），点击进入专辑详情。

### 社区
- **FR-5**: 搜索页「帖子」tab：真实检索 GET api/posts（keyword、分页），瀑布流卡片，点击进帖子详情；加载/错误/空态与安卓一致。
- **FR-6**: 发布动态页：标题/正文、最多 9 个媒体（图片/视频/实况）、关联歌曲、话题（选择+推荐）；发布为入队异步上传，发布后给明确反馈。
- **FR-7**: 后台任务管理：发布任务持久化；App 重启/被杀后恢复未完成任务（上传中/发布中重置为排队并重跑）；任务状态页展示 queued/uploading/publishing/failed/done，支持失败重试与取消；社区页提供发帖与任务状态页入口。

### 举报
- **FR-8**: 通用举报页（理由 spam/abuse/porn/copyright/illegal/other + 可选详细说明），POST api/reports（target_type/target_id/reason/description），覆盖歌曲、帖子、评论、用户四类入口，提交后明确反馈。
- **FR-9**: 设置 → 举报历史：GET api/reports 分页，展示对象类型、理由、说明、状态（待处理/处理中/已处理/已驳回）、时间；加载/错误/空态与加载更多。

### 歌曲菜单
- **FR-10**: 歌曲「更多」菜单包含与安卓一致的五项：下一首播放、添加到歌单、分享给好友、下载歌曲、举报；在所有歌曲列表场景（首页、发现、歌单/专辑详情、搜索、我的）可触发。

### 消息
- **FR-11**: 消息与会话本地持久化：发送、接收的消息写入本地；会话列表由本地数据驱动；杀进程重进后历史消息与会话仍在。
- **FR-12**: 可靠发送：消息先本地入库（sending）→ 持久化发送队列异步发送（网络约束、失败重试/标记 failed），聊天页展示 sending/sent/failed 状态与失败重试；离线发送不丢消息。
- **FR-13**: 用户资料页「分享」= 分享名片：进入分享选择好友页，选择好友后发送 user 类型名片消息；会话内可展示名片气泡并可点击跳转用户资料。
- **FR-14**: 聊天页可发送图片（相册/拍照）、视频（相册/录像）、文件；上传走现有 api/upload（image/video）与通用文件上传；消息气泡展示缩略图/文件信息，点击可预览；首次使用前申请对应权限。
- **FR-15**: 聊天页可发送语音：按住录音、松开发送、上滑取消，展示时长；语音气泡可播放（含播放状态）；首次使用申请麦克风权限。
- **FR-16**: 实时链路（WebSocket）收到的消息写入本地库并刷新会话/聊天页，去重正确；前台时即时可见，未读计数正确。

### 下载
- **FR-17**: 歌曲下载：获取 sourceUrl 后以 URLSession 下载，支持断点续传；下载任务与状态（排队/下载中/暂停/完成/失败、进度、字节数）持久化；按音乐 ID 去重；已下载歌曲在播放时使用本地文件。
- **FR-18**: 下载管理页（iOS 风格可独立设计）：存储占用概览、下载中/已完成分组、全部暂停/继续、单项暂停/继续/重试/删除/播放；设置提供「仅 Wi-Fi 下载」开关。

### 设置
- **FR-19**: 编辑资料页：头像更换（选图→裁剪→上传）、昵称、个性签名、邮箱（只读），保存调用更新资料接口；接口与调用顺序完全参考安卓。
- **FR-20**: 隐私设置页：私密账号、无法被搜索找到开关 + 黑名单列表（可解除）；状态与 API 对齐安卓。
- **FR-21**: 移除设置页「检查更新」条目。
- **FR-22**: 锁屏歌词 Live Activity（iOS 16.2+）：锁屏展示歌名/歌手、当前行与下一行歌词、播放进度；iOS 17+ 提供播放/暂停/上一首/下一首交互按钮（不打开 App 即可控制）；播放期间逐行更新，更新被系统节流时不报错、不崩溃。
- **FR-23**: 灵动岛：紧凑态（图标+歌词/歌名）与展开态（歌词两行+控制按钮）；无灵动岛设备由锁屏 Live Activity 承载。

## Non-Functional Requirements
- **NFR-1**: 所有受保护资源（麦克风、相册、相机）在 Info.plist 具备用途描述，并在首次使用时运行时申请；拒绝后入口给出引导而非崩溃。
- **NFR-2**: 新增代码遵循现有架构约定：数据/状态在 Kotlin 侧（CMP 页面复用 commonMain Content），SwiftUI 负责导航与系统能力；不出现跨语言 suspend/Flow，沿用回调风格。
- **NFR-3**: 本地持久化数据存放于合规目录（Application Support/Caches/Documents），iCloud 备份项最小化；后台任务不依赖私有 API。
- **NFR-4**: 新增 UI 符合 iOS HIG 与现有视觉风格，深色模式下颜色正确，不与迷你播放条/输入栏遮挡。
- **NFR-5**: 安卓端构建不受影响：改动 commonMain 共享代码时保持安卓编译通过。

## Constraints
- **Technical**: Kotlin 2.3.21 / CMP / Ktor Darwin / Swift 5 / iOS 16.0（Live Activity 16.2+，交互按钮 17+）；无 Room/SQLDelight iOS 目标，本地存储采用 JSON 文件 + 内存缓存（对齐 PlaybackPersistence 风格）。
- **Business**: 内部测试分发，不做应用商店更新链路。
- **Dependencies**: 现有后端接口（api/messages、api/reports、api/upload/*、api/albums、api/posts 等）；Xcode 工程新增 Widget Extension target 与 App Group 配置。

## Assumptions
- 通用文件上传接口存在（api/upload/file 或等价；安卓 SendMessageWorker 所用）；若实际不存在，文件消息改为先确认可用路径再实施。
- 后端举报 target_type 接受 music/post/comment/user 四类字符串（安卓已使用 music）。
- 播放期间 App 进程在后台存活（audio background mode），Live Activity 控制可通过 App Group/系统机制触达 PlayerModel。

## Acceptance Criteria

### AC-1: 主题背景跟随
- **Type**: `rule`
- **Given**: 用户在设置页切换深色模式或主题色
- **When**: 切换完成后不杀进程，浏览五个 Tab 及任意二级页
- **Then**: SwiftUI 背景与 CMP 页面背景、窗口状态栏补色均呈现新主题，无残留旧色板区域
- **Pass Condition**: 三种外观 × 至少 8 个页面切换后背景全部正确
- **Evidence**: 模拟器截图（浅色/深色/跟随系统各一组）+ 代码中无遗漏的硬编码背景

### AC-2: 全部歌单页
- **Type**: `rule`
- **Given**: 首页点击推荐歌单「更多」
- **When**: 切换分类 Tab、滚动网格
- **Then**: 分类完整、网格分页加载、点击歌单进入对应详情
- **Pass Condition**: 分类接口成功时 Tab 数与后端一致；滚动可加载 ≥2 页；点击跳转正确
- **Evidence**: 模拟器操作录屏/截图与网络请求

### AC-3: 推荐/新歌落地页与播放队列
- **Type**: `rule`
- **Given**: 首页为你精选更多 / 发现页新歌速递更多 / 首页与发现页列表直接点歌
- **When**: 进入落地页并滚动；在列表点歌后切下一首多次
- **Then**: 落地页为歌单列表形态（sort 正确、最多 100 条、pageSize=30）；直接点歌入队 ≥30 首，且首页列表本身只展示原有少量条目
- **Pass Condition**: recommend 与 latest 两落地页数据不重复；点歌后连续「下一首」≥10 次仍有歌
- **Evidence**: 模拟器验证 + 代码分页/队列配置

### AC-4: 全部专辑页
- **Type**: `rule`
- **Given**: 首页热门专辑点「更多」
- **When**: 滚动网格、点击专辑
- **Then**: 4 列网格分页（pageSize=20）、点击进专辑详情
- **Pass Condition**: 可加载 ≥2 页且跳转正确
- **Evidence**: 模拟器截图

### AC-5: 帖子搜索
- **Type**: `rule`
- **Given**: 进入搜索页切到「帖子」tab 并提交关键词
- **When**: 浏览结果、点击结果项
- **Then**: 瀑布流展示真实帖子分页，含加载/错误/空态，点击进帖子详情
- **Pass Condition**: 关键词有结果时展示帖子卡片；分页正常
- **Evidence**: 模拟器截图与请求参数

### AC-6: 发布动态
- **Type**: `rule`
- **Given**: 社区页点击发帖
- **When**: 填写标题/正文、添加媒体（图片/视频，最多9）、关联歌曲与话题后点发布
- **Then**: 任务进入上传队列并提示，媒体上传后帖子创建成功
- **Pass Condition**: 纯文本与图文两种发帖均成功；社区可刷出新帖
- **Evidence**: 发布队列状态变化 + 帖子出现在列表

### AC-7: 发布后台任务管理
- **Type**: `rule`
- **Given**: 有发布任务（含失败任务）
- **When**: 杀进程重启 App；在任务状态页重试/取消
- **Then**: 未完成任务重启后恢复为排队并继续处理；失败可重试成功、可取消消失；状态实时更新
- **Pass Condition**: 杀掉 App 重启后 queued 任务仍在且最终成功；取消后列表移除
- **Evidence**: 任务持久化文件 + 重启前后任务页截图

### AC-8: 举报提交
- **Type**: `rule`
- **Given**: 分别从歌曲菜单、帖子、评论、用户主页触发举报
- **When**: 选择理由（可填说明）提交
- **Then**: POST api/reports 参数正确，提交后提示成功；四类入口均可用
- **Pass Condition**: 四类 target_type 各成功提交一次（后端可查）
- **Evidence**: 请求体与后端记录

### AC-9: 举报历史
- **Type**: `rule`
- **Given**: 设置 → 举报历史
- **When**: 浏览、下拉、滚动
- **Then**: 分页展示举报记录，类型/理由/状态/时间中文映射正确，含空态
- **Pass Condition**: AC-8 的举报出现在列表，状态展示正确
- **Evidence**: 模拟器截图

### AC-10: 歌曲更多菜单
- **Type**: `rule`
- **Given**: 任意歌曲列表场景
- **When**: 点更多并逐项操作
- **Then**: 下一首播放（队列插入并可立即下一首听到）、添加到歌单（选歌单后调用成功）、分享给好友（可走系统分享/名片）、下载歌曲（任务出现）、举报（举报页打开）五项均真实生效
- **Pass Condition**: 五项各验证一次成功；菜单在 ≥6 个列表场景可打开
- **Evidence**: 逐项操作结果

### AC-11: 消息本地持久化
- **Type**: `rule`
- **Given**: 发送过消息的会话
- **When**: 退出页面看会话列表；杀进程重进该会话
- **Then**: 会话列表含该会话与最后消息预览；重进后消息仍在
- **Pass Condition**: 杀进程后会话与消息均不丢失
- **Evidence**: 本地存储文件 + 重启前后对比

### AC-12: 可靠发送与状态
- **Type**: `rule`
- **Given**: 正常与断网两种环境
- **When**: 发送消息、断网发送后恢复网络、对失败消息点重试
- **Then**: 气泡即时出现并显示发送中→已 sent；断网时标 failed 且消息留存，恢复后重试可成功
- **Pass Condition**: 断网发送不丢、联网重试成功；状态图标正确
- **Evidence**: 聊天页状态变化截图

### AC-13: 名片分享
- **Type**: `rule`
- **Given**: 用户资料页点分享
- **When**: 在选择好友页选好友确认
- **Then**: 发送 share_type=user 名片；接收方会话出现名片气泡，点击可打开该用户资料
- **Pass Condition**: 自己账号可见名片消息且点击跳转正确
- **Evidence**: 消息体与聊天页截图

### AC-14: 图片/视频/文件消息
- **Type**: `rule`
- **Given**: 聊天页
- **When**: 首次使用时允许权限；分别从相册选图/视频、拍照/录像、选择文件发送
- **Then**: 上传成功后消息气泡展示图片缩略/视频标识/文件信息；点击可全屏看图、播放视频、打开或分享文件
- **Pass Condition**: 四类附件各发送并展示成功；拒绝权限时有引导提示
- **Evidence**: 聊天页截图与权限弹窗

### AC-15: 语音消息
- **Type**: `rule`
- **Given**: 聊天页首次使用语音
- **When**: 允许麦克风；按住录音、上滑取消、松开发送；点击语音气泡
- **Then**: 取消的不发送；发送的展示时长并可播放（播放中状态、听筒/扬声器合理）
- **Pass Condition**: 录音-发送-播放闭环成功；取消手势有效
- **Evidence**: 操作过程与语音消息展示

### AC-16: 实时消息入库
- **Type**: `rule`
- **Given**: 保持登录并处于聊天页或会话列表
- **When**: 对端发来消息
- **Then**: 消息即时入库并出现在 UI，会话排序/未读更新，重复推送不产生重复消息
- **Pass Condition**: 同一消息 WebSocket 多次投递仅一条
- **Evidence**: 实时日志与 UI 截图

### AC-17: 下载引擎
- **Type**: `rule`
- **Given**: 对歌曲触发下载（含 Wi-Fi/蜂窝两种网络与中途暂停/杀进程场景）
- **When**: 下载中暂停再继续、杀进程重启、播放已下载歌曲
- **Then**: 进度持久化、断点续传成功；任务重启后可恢复；已下载歌曲播放本地文件且离线可播
- **Pass Condition**: 50% 处暂停→继续后文件完整可播；离线播放成功；同 ID 重复下载不产生重复任务
- **Evidence**: 下载任务数据 + 文件校验（大小/可播放）

### AC-18: 下载管理页
- **Type**: `rubric`
- **Dimension**: 功能完整性与 iOS 设计质量
- **Scale**: 1-5

- **Pass Threshold**: >= 4
- **Evidence**: 下载管理页各状态截图

### AC-19: 编辑资料
